# ቅዳሜ Bingo (Ezi Bingo) — ንጹህ የቢንጎ ፕሮጀክት (Pure Bingo Project)

ይህ ፎልደር **የቢንጎ ጨዋታን ብቻ** (Fast Bingo + Regular Bingo) የያዘ ራሱን የቻለ የተሟላ የReact + Vite + TypeScript ፕሮጀክት ነው። ምንም ዓይነት የሉዶ ኮድ የለውም።

---

## 🚀 በ Render (Onrender.com) ላይ ለመጫን (Recommended)
1. ወደ [dashboard.render.com](https://dashboard.render.com) ይግቡ።
2. **New +** → **Static Site** ይምረጡ።
3. ኮዱን የጫኑበትን የ GitHub Repository ያገናኙ።
4. የሚከተለውን ያስገቡ፦
   - **Build Command:** `npm install && npm run build`
   - **Publish Directory:** `dist`
5. **Create Static Site** ይጫኑ። በ1 ደቂቃ ውስጥ ላይቭ ይሆናል!

---

## ⚡ በ Vercel ላይ ለመጫን
1. ወደ [vercel.com](https://vercel.com) ይግቡ።
2. **Add New Project** ብለው ሪፖዚቶሪዎን ያስገቡ።
3. **Deploy** ይጫኑ (Vite ፕሮጀክት መሆኑን ራሱ ያውቀዋል)።

---

## 💻 በኮምፒውተርዎ ላይ ለማስኬድ (Local Run)
```bash
npm install
npm run dev
```
ብሮውዘርዎን ከፍተው `http://localhost:3000` ላይ ይጫወቱ።

---

## 📦 የምርት ፋይል (Production Build)
```bash
npm run build
```
ይህ ትእዛዝ የተጠናቀቀውን `dist/` ፎልደር ያዘጋጅልዎታል።
